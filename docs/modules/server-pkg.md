# Server Pkg

共享工具包集合。提供加密、错误处理、HTTP 响应、文件存储、GitHub API 客户端和媒体代理等基础能力。

## Sub-modules

| Sub-module | Doc | Description |
|---|---|---|
| crypto | `modules/server-pkg/crypto.md` | AES 加解密工具 |
| errs | `modules/server-pkg/errs.md` | 统一错误码定义 |
| response | `modules/server-pkg/response.md` | HTTP 响应格式化 |
| storage | `modules/server-pkg/storage.md` | 文件存储抽象层 |
| github | `modules/server-pkg/github.md` | GitHub API 客户端封装 |
| githubmedia | `modules/server-pkg/githubmedia.md` | GitHub 媒体资源代理 |
